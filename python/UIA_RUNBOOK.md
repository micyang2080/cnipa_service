# cpquery 免 CDP 实跑手册（UIA 轨道）

瑞数 antibot 拒绝一切 CDP/调试端口形态 → 本轨道用 OS 级 pywinauto(UIA) +
SendInput 真实键鼠，驱动用户日常 Chrome 125（须以 `--force-renderer-accessibility`
启动）。02/03 已实跑通过；04 为点击→收割→OCR 流水线（待实跑验证）。

## 铁律（每个脚本通用）

1. **Agent 永不直跑网站**（封号风险）——所有实跑命令由用户在本机执行；
   Agent 只做离线验证（py_compile → selftest → 真实 dump 回放）。
2. **实跑失败不重跑**——Agent 从 `output/uia_runs/<run>/` 的 payload/树/截图
   /OCR dump 做根因分析，修复后才允许下一次实跑（首跑即探针：全程落盘）。
3. **每次截图前必须 `set_focus`**——17:40 教训：等待期用户切窗，截到 Cowork
   叠加层（04 收割循环已内置）。
4. pywinauto：legacy_properties() 的键是大写 `Value`；树有双枚举，须去重；
   屏外节点 rect 为 0（用「实矩形」判定后再点击，否则先滚动带回）。

## 04 流水线（2026-09-01 定案）

**进页**：在已有结果页上真实点击第一张卡片标题链接（a11y 纯 Text 无 Button
→ 几何坐标真鼠标点击），详情新标签打开。
✗ 旧案 Ctrl+T 直敲 detail/index URL：40s 只渲染出壳。page1 地址栏实锤根因——
**URL 参数是会话加密 token**（`zhuanlisqh=pZTOc…%3D%3D`），离站直入必然失效。

**正文**：右栏决定书是**整页图片**渲染（Group 下约 9 张 Image、零 Text）→
UIA 文本通道永远拿不到，唯一文本化通道 = 滚动截图 + Windows zh-CN OCR
（`ocr_winrt.ps1` 输出行级词框并集）。

**版式与解析**（`cnipa_ocr.py` 带框层）：

- 首屏：顶栏摘要条 + 决定书头（（第38430号））+ **勾选框结论**三选一行
  （囗=未选 / 冈=勾选；取未带囗/□前缀者）；
- 第二屏：信息表 = 标签列(x≈708-834) × 值列(x≈951+) **逐行同 y 对齐** →
  同排右值连接 + 同列续行吸附（标题跨 2 行实测可拼全）；
- 表末「决定要点」全宽多行正文，**可能溢出到第 3 屏**（用户 18:01/18:04：
  前 2 屏通常已含全部 12 列，但不排除溢出）→ 收割循环滚屏直到
  （请求日/法律依据/要点齐备）且（见合议组 或 要点不再增长），上限 4 屏；
- **合议组签名栏在决定书首页底部**（用户 18:30 page1-info.png 实证），
  首屏折叠线下方一点，第 2/3 屏收割必经；实测 OCR 把它拆成同排三碎片
  （'厶议组组长：任跷兰'｜'主审'｜'：文妒'，参审在下排，右侧同排还有落款
  '专利复审委员会'）→ `_panel_line`：尾段锚 '议组组长'（合→厶 兜底）+
  短形 '主审'/'参审'，同排+下排 ≤45px 短行按 (行,列) 拼块，排除
  委员会/盖章/联系/决定书；人名本身 OCR 有噪声（跷兰=晓兰），该列仅
  供参考、不做结构化；
- OCR 噪声容错：凵→日（决定日/申请日误识）、'；' 分隔、锚词尾段命中
  （'编号'/'定号'），误识样本冻结于 `ocr_fixtures_detail.py`。

**12 列合并**：卡片 8 列（02/03 结果页 a11y 精确值）无条件覆盖 OCR 噪声值
（卡片专利权人=当前权利人，与决定书原文的原始权利人不同，属预期）；
OCR 的「决定日」（决定书落款 20181221）优先于卡片「发文日」（20181228）；
request_date / legal_basis / decision_summary / panel_members 仅 OCR 提供。

**收尾**：新开标签 → Ctrl+W 关之；同标签路由 → Alt+←；`keep_tab:true` 跳过。
